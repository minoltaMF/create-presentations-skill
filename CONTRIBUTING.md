# Contributing

Contributions that improve portability, presentation quality, deterministic validation, examples, and documentation are welcome.

Before opening a pull request:

1. keep `SKILL.md` concise and provider-neutral;
2. place detailed guidance in one-level-deep files under `references/`;
3. do not add credentials, paid calls, runtime downloads, or hidden Provider assumptions;
4. add attribution before reusing upstream code or assets;
5. run `python3 scripts/validate_repo.py`;
6. render and inspect any changed presentation example.

For large workflow changes, open an issue first and describe the user scenario, proposed behavior, and validation approach.
