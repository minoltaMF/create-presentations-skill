# Style gallery assets

These sixteen full-slide PNG files are the original image-generation outputs used by the public style gallery.

- Canvas: 1672 × 941, approximately 16:9.
- Shared subject: the `create-presentations` Skill itself.
- Shared visible copy: `CREATE PRESENTATIONS`, `Brief → Design → Build → Deliver`, and `STYLE STUDY`.
- Generation route: Codex built-in OpenAI image-generation tool.
- Model identifier: not surfaced by the built-in execution receipt; prompts are compatible with `gpt-image-2` and other full-slide image backends.
- Post-processing: none beyond file copying and deterministic montage generation.

See [`docs/STYLE_GALLERY.md`](../../docs/STYLE_GALLERY.md) for selection guidance and style descriptions.
