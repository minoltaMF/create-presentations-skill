# Visual Style Gallery

The gallery uses one subject and one visible-copy set across every sample so the comparison is about visual direction rather than content.

**Visible copy:** `CREATE PRESENTATIONS` · `Brief → Design → Build → Deliver` · `STYLE STUDY`

![Sixteen presentation style studies](../assets/readme/style-gallery.png)

Every direction must vary in at least four dimensions: composition, typography, image treatment, and emotional tone. A palette-only variation is not a separate style.

## How to use the gallery

1. Pick the closest **family**, not an exact template.
2. Adapt its Design DNA to the topic, audience, brand, and delivery route.
3. Produce one representative page when visual ambiguity or generation cost is meaningful.
4. Keep one visual system across the deck; treat page-level deviations as intentional exceptions.
5. Save a successful custom direction as a reusable style reference with its prompt, palette, typography, image treatment, and failure constraints.

## Generation provenance

- Generated as full-slide images with the Codex built-in OpenAI image-generation tool.
- The built-in tool did not surface a model identifier in the execution receipt; the prompt pack remains compatible with `gpt-image-2` and other full-slide image backends.
- Every sample used the same short visible-copy manifest and prohibited extra dates, percentages, filenames, UI labels, and prompt leakage.
- Original files are preserved under [`assets/style-gallery`](../assets/style-gallery/).

The gallery is original output. Public presentation projects were reviewed for workflow and style-family coverage; their screenshots and templates were not copied into this repository.
