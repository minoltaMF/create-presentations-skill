# Example: Becoming an AI FDE

This worked example demonstrates the complete Skill workflow with a small, provider-free Native deck and a reusable AI-generated visual master on the cover.

## Communication job

By the end, experienced product, engineering, and business professionals should understand that becoming an AI FDE is a shift toward owning outcomes across discovery, prototyping, integration, and adoption—and should be able to choose a practical first project.

## Contents

- `brief.md` — presentation Brief;
- `page-plan.md` — flexible, stable-ID page narratives;
- `source-ledger.md` — supplied/researched/viewpoint boundary;
- `ai-fde-career-demo.pptx` — editable Native PPTX;
- `ai-fde-career-demo.html` — portable browser sample;
- `renders/` — full-size slide previews;
- `contact-sheet.png` — whole-deck rhythm review;
- `deck-manifest.json` — validated delivery evidence.

## Route

- Primary: Native PPTX
- Companion: HTML
- Visual master: AI-generated, no text; deterministic native text overlay
- Paid Provider calls in this example: none during deck assembly

This is a workflow demonstration, not a claim that the illustrative career framework is an industry standard.
