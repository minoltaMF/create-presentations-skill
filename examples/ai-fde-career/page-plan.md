# Page plan

## slide-01 — AI FDEs own the path from ambiguity to adoption

- Communication job: define the transition in one sentence.
- Page role: minimal cover and thesis.
- Visible copy: “Become an AI FDE”; “Own the path from ambiguity to adoption.”
- Visual role: AI-generated paper-flight visual with deterministic native typography.

## slide-02 — The role joins four kinds of work

- Communication job: make the cross-functional scope concrete.
- Page role: four-part capability map.
- Visible copy: discover, prototype, integrate, enable adoption.
- Visual role: one continuous path, not four disconnected cards.

## slide-03 — Your current strength is the starting point

- Communication job: help three audience profiles locate an entry path.
- Page role: three-lane comparison.
- Visible copy: product, engineering, business starting strengths and next moves.

## slide-04 — Build evidence through one real workflow

- Communication job: replace abstract learning with a practical project loop.
- Page role: sequence.
- Visible copy: problem, prototype, integration, feedback, measurable adoption.

## slide-05 — A 30-day starter plan creates momentum

- Communication job: make the transition feel actionable.
- Page role: timeline.
- Visible copy: observe, build, ship, teach.

## slide-06 — Choose the problem you are willing to own

- Communication job: end with a concrete decision.
- Page role: closing action.
- Visible copy: choose one workflow, one user group, and one measurable outcome.
