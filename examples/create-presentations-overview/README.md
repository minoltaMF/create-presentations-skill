# Example: Create Presentations

This self-referential worked example uses the Skill's own workflow to explain the Skill.

## Included outputs

- `create-presentations-overview.pptx` — 10-page editable/Hybrid overview;
- `create-presentations-style-showcase.pptx` — 16 full-slide Visual Locked style samples;
- `create-presentations-overview.html` — portable browser presentation;
- `brief.md`, `page-plan.md`, and `source-ledger.md` — planning evidence;
- `renders/` and `contact-sheet.png` — visual inspection evidence;
- `deck-manifest.json` — delivery hashes, routes, and limitations.

![Create Presentations overview contact sheet](contact-sheet.png)

## What the example demonstrates

1. Define the communication job before choosing layouts.
2. Keep narrative, approved visible copy, visual direction, model routing, and delivery formats separate.
3. Use one deck-level Design DNA while varying page roles and silhouettes.
4. Compare style directions with identical copy.
5. Choose Native, Visual, Hybrid, Template, or HTML before production.
6. Render every page and inspect the full sequence before delivery.

The style-showcase PPTX uses original full-slide image-generation outputs. The overview PPTX keeps its primary copy and diagrams editable while embedding the visual gallery as a raster asset.
