# Presentation Brief

## Communication job

By the end, people evaluating an Agent Skill for presentation work should understand how `create-presentations` separates narrative, visible copy, visual direction, production route, and delivery evidence—and should be able to install it and choose an appropriate route for their next deck.

## Audience and context

- Codex, Claude Code, and compatible Agent users.
- Creators, product teams, consultants, educators, and technical teams.
- GitHub README discovery, installation evaluation, and workflow demonstration.

## Thesis

A strong presentation workflow is not one prompt followed by one file. It is a sequence of explicit decisions that can be revised independently and delivered through the route the audience can actually use.

## Delivery

- 10-page editable/Hybrid overview PPTX.
- 16-page Visual Locked style-showcase PPTX.
- Portable HTML overview.
- Slide renders, contact sheet, and delivery manifest.

## Visual direction

Creator Paper Editorial: warm uncoated paper, cobalt structural planes, one amber signal, restrained rules, decisive typography, and varied page silhouettes.
