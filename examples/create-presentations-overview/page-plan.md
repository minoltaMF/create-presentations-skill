# Page plan

## 01 — Create presentations, not slide files

- Job: establish the promise and the four-stage arc.
- Route: full-slide Visual image.
- Visible copy: generated style-study cover.

## 02 — A deck is five decisions, not one prompt

- Job: introduce the separable system.
- Visible copy: Narrative; Visible copy; Visual system; Production route; Delivery evidence.

## 03 — Plan communication jobs before layouts

- Job: show flexible page narratives and cumulative pacing.
- Visible copy: Open; Frame; Explain; Compare; Prove; Resolve.

## 04 — Choose the route before you build

- Job: explain Native, Visual, Hybrid, Template, and HTML without ranking them universally.

## 05 — Route each model to the work it does best

- Job: separate reasoning, image generation, and deterministic rendering.

## 06 — One brief can support sixteen visual systems

- Job: demonstrate materially different deck-level visual directions on identical content.
- Asset: `assets/readme/style-gallery.png`.

## 07 — Approved copy and visual instructions are different inputs

- Job: explain visible-copy integrity for image-first slides.

## 08 — Render, inspect, revise

- Job: make QA a required production stage rather than an afterthought.

## 09 — Deliver the format the audience can actually use

- Job: connect route decisions to editable, visual, hybrid, template, HTML, PDF, and evidence outputs.

## 10 — One skill, multiple production routes

- Job: close with a concrete next action: install, provide a brief or files, choose a route, and build.
