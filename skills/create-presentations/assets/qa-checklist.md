# Presentation QA checklist

## Narrative

- [ ] One communication job per slide
- [ ] Sequence is cumulative and non-repetitive
- [ ] Opening and closing resolve the same central question

## Copy

- [ ] Audience-facing language only
- [ ] Approved titles, values, dates, names, and URLs checked
- [ ] No internal prompt or production instruction leakage
- [ ] Sources and speaker notes retained where needed

## Visual

- [ ] One coherent deck-level system
- [ ] Adjacent slide silhouettes vary intentionally
- [ ] Images are sharp and correctly cropped
- [ ] Charts and diagrams improve rather than complicate understanding

## File

- [ ] Correct page count and aspect ratio
- [ ] No unintended overlap, clipping, wrapping, or off-canvas content
- [ ] Fonts and CJK fallbacks render correctly
- [ ] Notes, links, tables, charts, and animations survive the chosen route
- [ ] Editable and rasterized regions disclosed

## Delivery

- [ ] Final files open in the target application
- [ ] Scratch renders and failed variants excluded
- [ ] Manifest validates when required
